# Core Rebuild 2b-ii-a: Enums and `match`

**Goal:** enums with unit and field variants and methods, variant construction (`Block.Air`, `Block.Stone(hardness: 3)`), exhaustive `match` with in-place bindings, enum printing, all through JIT and exe.

**Spec:** syntax spec (enums, `match`), core spec §2 (an enum is a u8 tag plus a union sized to its largest variant).

**Execution note:** written for and executed by the controller directly (subagents were rate-limited), TDD per step, with a review pass afterwards.

## Design

- **Syntax:** `enum Name { Variant  Variant { f: T, g: U }  methods }`. Variants go one per line. A variant's fields are separated by commas or newlines and have no defaults.
- **Construction** reuses existing syntax. `Name.Variant` is a field access on the enum's name, and `Name.Variant(args)` is a method call on it. The checker resolves them when the base is an enum name and not a variable. Arguments bind to fields like constructor arguments, and evaluate in source order.
- **`match value { arms }`**, where an arm is `Variant { block }`, `Variant name { block }` or `else { block }`. Arms need no separators, because the lexer drops the newline before `else` and `}`.
  - Every variant is handled or there's an `else`.
  - Errors: duplicate arms, unknown variants, arms after `else`, and matching on a non-enum.
  - `match` is an expression typed like `if`.
- **Bindings** have type `Ty::Variant(enum, variant)` and are usable only as `binding.field`.
  - A binding aliases the matched place: `LocalInfo::alias` points to the root variable, so it can be changed when the root can, and `var`/exclusivity rules see the root.
  - A matched value that isn't a place is first stored in a temporary.
- **Types:** `Ty::Enum(EnumId)`, `Ty::Variant(EnumId, u32)`, and `KTy::Enum(EnumIdx)`, which is an aggregate.
- **KIR:**
  - `Module::enums: Vec<EnumLayout>`. The tag is a u8 at offset 0, and each variant's fields are laid out from a shared payload offset.
  - Place projections become `Proj::Field(u32)` and `Proj::Variant(variant, field)`.
  - New expressions: `ExprKind::VariantLit(EnumIdx, u32, Vec<Expr>)` and `ExprKind::Tag(Place)`, which yields a u8.
  - `match` lowers to an if-chain on the tag. When the arms are exhaustive with no `else`, the last arm is unconditional.
- **Codegen:**
  - Enums are copied as raw bytes, using the widest aligned chunks.
  - A variant literal stores the tag and then its fields.
  - `Tag` loads a byte.
  - Printing shows `Block.Air` and `Block.Stone(hardness: 3)`.

## Steps

1. **Parser:** `EnumDecl`/`VariantDecl` items, plus `ExprKind::Match` with `MatchArm`/`Pattern`. Parser tests.
2. **Checker:** enum collection (names, variants, methods), enum types, variant construction, `match` typing and exhaustiveness, and alias bindings. Checker tests (ok cases and every error).
3. **KIR:** enum layouts, `Proj`, variant literals, `Tag`, `match` lowering, and binding places. KIR tests.
4. **Codegen:** byte copies, variant literals, `Tag`, projections through variants, and enum printing. JIT tests, including in-place mutation through a binding.
5. **End to end:** program tests (`enums.kes`, the spec's `take_damage` example) and error tests.
