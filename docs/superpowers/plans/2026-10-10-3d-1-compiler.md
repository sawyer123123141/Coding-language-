# 3D plan 1: compiler pieces for textures and meshes

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the compiler and runtime pieces the texture and 3D work needs, none of which needs a window: `vec3.cross`, native array parameters and struct results, the owning `GpuHandle` type, heap constants built once, and native runtime errors that name the line.

**Architecture:**
- **`cross`** is one more vector method: `Builtin::Cross`, typed for `vec3` only, lowered to a `StructLit` of products.
- **Natives** may take `[T]` of plain values (a `list[T]` argument is accepted there), structs whose fields are arrays or lists of those, and may return structs of numbers, vectors and GPU handles. Only the checker changes; the calling convention already passes aggregates by pointer and returns them through a result pointer.
- **`GpuHandle`** (`Ty::Gpu` / `KTy::Gpu`, 8 bytes in memory, like `Arena`) is owning, so a struct holding one moves and is dropped. Its drop is `Stmt::DropGpu(place)`, which calls the runtime's `kestrel_rt_gpu_drop(id)`. That forwards to a hook the window crate sets in plan 2. Only built-in modules may name the type; the driver tells the checker which source ranges are built-in.
- **Heap constants** (a type holding an array, list or map) become globals: one data slot each in the compiled module, built by a generated `__kestrel_constants` function into a constants arena that is never freed. A use reads the global through a reference local (`Stmt::BindGlobal`), so every existing place rule applies: reads don't copy, and stores copy, because a reference local is never moved from. `main` calls the init first; hosts (codegen tests, the Godot add-on) call it through `JitProgram::run_init` / `init_thunk`.
- **Native error lines:** before each call from a program's own code to a built-in function that isn't `pure`, KIR has `Stmt::SetLine(line)`. Codegen turns it into a plain store into the runtime's `kestrel_rt_call_line`. Natives fail through `kestrel_runtime::panic::fail_at_call`, which appends "on line N".

**Tech Stack:** Rust workspace `kestrel/` (syntax, check, kir, codegen on Cranelift 0.116, runtime, driver, window, cli) and `kestrel/godot` (godot-rust 0.5.5). No new crates.

**Spec:** `docs/superpowers/specs/2026-10-10-3d-textures-design.md`: read "Language additions", "GPU objects", "Natives" and the hoisted-constants and error-lines bullets of "How it's built" first.

## Review Focus

The five failure modes the spec implies that tests most easily miss, with the task that pins each:

1. **A heap constant read from many `par for` threads at once:** nothing may write to the shared global, including a map lookup or loop, or `.len`. Task 4 tests a `par for` that reads a list constant and calls a `pure` function that loops over a map constant.
2. **A constant used only inside another constant**, possibly declared later or in another file: it must be built first. Task 4 tests `NESTED = [ITEMS, ...]` with `ITEMS` declared below it and used nowhere else.
3. **Code run by a host without `main`** (codegen tests, the Godot add-on) must see built constants. Task 4 makes the codegen test helpers call `run_init`, and Task 5 checks the add-on.
4. **A GPU object's drop runs exactly once** in every case: overwriting, moving into a list, returning from a function, inside an optional, and inside a struct field that is replaced. Task 3's codegen test checks the dropped ids.
5. **A native's error line when its arguments call another built-in** on a different line: the error must name the outer call's line. Task 6 tests a call split over two lines.

/// A value a native can read straight from an array's memory: a number, a bool,
/// or a struct of those (vectors and colours are structs of floats).
fn plain(t: &Tables, ty: Ty) -> bool {
    match ty {
        Ty::Int | Ty::I64 | Ty::U8 | Ty::Float | Ty::F64 | Ty::Bool | Ty::Error => true,
        Ty::Struct(s) => t.strukt(s).fields.iter().all(|f| plain(t, f.ty)),
        _ => false,
    }
}

/// `[T]` or `list[T]` (as `list` allows) of a plain `T`.
fn plain_seq(t: &Tables, ty: Ty, list: bool) -> bool {
    match ty {
        Ty::Array(e) => plain(t, t.elem(e)),
        Ty::List(e) => list && plain(t, t.elem(e)),
        _ => false,
    }
}

fn param_ok(t: &Tables, ty: Ty) -> bool {
    match ty {
        Ty::Struct(s) => t.strukt(s).fields.iter().all(|f| simple(f.ty) || plain(t, f.ty) || plain_seq(t, f.ty, true)),
        Ty::Enum(e) => t.enm(e).variants.iter().all(|v| v.fields.is_empty()),
        Ty::Array(_) => plain_seq(t, ty, false),
        other => simple(other),
    }
}

fn result_ok(t: &Tables, ty: Ty) -> bool {
    match ty {
        Ty::Struct(_) => plain(t, ty),
        other => simple(other) && other != Ty::Str,
    }
}
```

/// A native's `[T]` parameter also takes a `list[T]`: a native reads only the
/// `{ptr, len}` that both headers start with.
fn check_native_array_arg(&mut self, e: &Expr, want: Ty) {
    let found = self.check_expr(e, Some(want));
    if found == Ty::Never {
        self.reject_never(e, found);
        return;
    }
    if let (Ty::List(have), Ty::Array(need)) = (found, want) {
        if self.t.elem(have) == self.t.elem(need) {
            return;
        }
    }
    self.coerce(e, found, want);
}

//! GPU objects (textures, meshes) are owned by Kestrel values holding a
//! `GpuHandle`. Dropping one calls `kestrel_rt_gpu_drop` with its id, which the
//! runtime hands to the hook the window crate sets. 0 means no object.
use std::sync::OnceLock;

static DROP_HOOK: OnceLock<fn(i64)> = OnceLock::new();

/// Sets what dropping a GPU object does. The first hook set stays.
pub fn set_drop_hook(hook: fn(i64)) {
    let _ = DROP_HOOK.set(hook);
}

/// Called by compiled code when a value holding a `GpuHandle` is dropped. It may
/// run on any thread (a `par for` pool thread too), so a hook must be thread-safe.
#[no_mangle]
pub extern "C" fn kestrel_rt_gpu_drop(id: i64) {
    if id != 0 {
        if let Some(hook) = DROP_HOOK.get() {
            hook(id);
        }
    }
}
```

**Lowering design:**
- **`FnLowerer`** gets `const_locals: HashMap<ConstId, LocalIdx>`.
  - `const_local(c)` returns the function's reference local for constant `c`, creating it on first use: `Local { name: <the constant's name>, ty, kind: LocalKind::RefParam }`.
  - It registers the constant's global in `Helpers` (`helpers.const_global(c, ty) -> GlobalIdx`, which allocates the next global the first time).
  - At the end of `lower()` (and of `lower_init`), prepend one `Stmt::BindGlobal(local, global)` per entry, ordered by local index so the output is deterministic.
- **A use of a hoisted constant:** the `Res::Const(c)` arm in `expr()` becomes `ExprKind::Load(Place::local(self.const_local(c)))`. `place()` returns `Some(Place::local(self.const_local(c)))` for an identifier that resolves to a hoisted constant. Everything else follows from existing rules:
  - Indexing, `.len`, `for in`, map lookups and read-only arguments read the global in place.
  - `owned()` copies any `Load` from a `RefParam` local, so `let p = PALETTE`, storing it in a field, `list.add(PALETTE)` and `return PALETTE` all copy.
  - A `par for` body captures the reference local by pointer like any other variable.
  - Map loops over a constant take no lock: `check_map_for_in` locks only changeable roots, and a constant isn't one. Don't change that; the test below pins it.
- **The init function,** built in `lower()` after every user function is lowered, when `helpers` has registered any constant:
  1. The constants to build are the registered ones plus every constant they use, recursively. A constant's uses are the `Res::Const` identifiers in its initializer's AST; write a small walker in `consts.rs` over the expression kinds `is_const_expr` allows.
  2. Keep those that are hoisted, in `t.const_order` order, so each comes after the ones it uses.
  3. Lower `__kestrel_constants` with a `FnLowerer` created for it (`lower_init`; `fn_id` is only read by `lower()`, so pass any valid id and don't call `lower()`). Its body:

```
BindGlobal(built_local, GlobalIdx(0)); BindGlobal(arena_local, GlobalIdx(1)); <BindGlobal for each constant>
If { cond: Load(built_local), then_body: [Return(None)], else_body: [] }
Assign(built_local, Bool(true))
PushArena(Some(Place::local(arena_local)))      // created on first push, never freed
Assign(Place::local(const_local(c)), self.value(&decl.value))   // for each constant, in order
PopArena { free: false }
```

/// that isn't `pure` (0 before the first). Compiled code stores it just before such

#[allow(non_upper_case_globals)]

/// Fails with `msg` and the line of the call into the built-in function that is
/// failing: "draw.circle was called before window.open on line 12".
pub fn fail_at_call(msg: &str) -> ! {
