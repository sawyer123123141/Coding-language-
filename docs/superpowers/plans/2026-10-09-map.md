# `map[K, V]` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add insertion-ordered hash maps (`map[K, V]`) to Kestrel, with GDScript-style `{}` literals, `get`, `has`, `remove`, `len`, `for k, v in m`, plus string `==`.

**Architecture:** A map value is a 64-byte header; entries and an open-addressing index table live in the map's arena. A new runtime module (`runtime/src/map.rs`) finds, inserts, removes and copies entries. Compiled code reads the header directly for `len`, loops and value access. The checker gets `Ty::Map`. KIR gets `KTy::Map`, one `ExprKind::Map(MapOp, Place, args)` family, `Stmt::MapSet` / `Stmt::MapUnlock`, and `Proj::MapKey` / `Proj::MapValue`. Codegen lowers these in a new `func/maps.rs`.

**Tech Stack:** Rust workspace `kestrel/` (syntax, check, kir, codegen on Cranelift 0.116, runtime staticlib, cli).

**Spec:** `docs/superpowers/specs/2026-10-09-map-design.md` (read it first; layouts and rules are there).

## Global Constraints

- Source files stay under about 400 lines; new map code goes in new files: `runtime/src/map.rs`, `check/src/body/maps.rs`, `kir/src/lower/maps.rs`, `kir/src/lower/map_helpers.rs`, `codegen/src/func/maps.rs`.
- Error messages are plain sentences that say what to do.
- Run everything from `kestrel/`: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`.
- Program tests: `tests/programs/*.kes` with `// expect:`, `// expect-exit:`, `// expect-stderr:`. Error tests: `tests/errors/*.kes` with `// error <line>: <message>`.
- Write files containing `\n` or `\\` with the Write/Edit tools, not shell heredocs (a hook mangles escapes).
- Header offsets (spec): entries 0, count 8, used 16, cap 24, slots 32, slot_count 40, locks 48, arena 56. Entry: hash u32 @0, live u8 @4, key @8, value @`val_off`.
- Key kinds: 0 = 1 byte (`bool`, `u8`), 1 = 4 bytes (`int`), 2 = 8 bytes (`i64`), 3 = string.

  - `kestrel_rt_map_dup(map: *mut Map, entry_size: i64, entry_align: i64)`

- [ ] **Step 1: Write the failing tests** at the bottom of `map.rs` (a `#[cfg(test)] mod tests`). They drive the functions as compiled code would, with `int` keys (kind 1) and an `int` value at offset 12 (entry size 16, align 8):
  - insert 1..=1000, find each, value bytes round-trip; `count` is 1000;
  - insert the same key twice gives the same entry, `count` unchanged;
  - remove returns 1 then 0; find gives null after remove;
  - order: insert 1, 2, 3, remove 2, insert 4 → live entries in order 1, 3, 4 (walk `entries` by `used`, skip `live == 0`);
  - churn: 10,000 rounds of insert `n`, remove `n - 8` keep `cap` at most 32 (compaction in place);
  - string keys (kind 3) with equal bytes at different addresses find each other;
  - `dup` gives a compact, independent copy with `locks == 0`;
  - `str_eq` true/false cases, including empty strings with null pointers.
- [ ] **Step 2: Run** `cargo test -p kestrel-runtime map` and see it fail to compile.
- [ ] **Step 3: Implement** per the spec's "Runtime" section:
  - hash: integers `(v as u64).wrapping_mul(0x9E37_79B9_7F4A_7C15) >> 32`; strings FNV-1a 64 folded to 32 bits;
  - probe from `hash & (slot_count - 1)`; `-1` ends a probe, `-2` is skipped;
  - insert: an existing key returns its entry even when locked; a new key panics when `locks > 0` with "can't add a key to a map while looping over it (line N); collect the keys in a list and change the map after the loop"; when `used == cap`, compact in place if at least half are removed, else grow (new `cap = max(2 * cap, 8)`, compacting while copying, arrays from the map's arena; null arena means the program arena); then rebuild the table (`slot_count = 2 * cap`);
  - remove panics similarly ("can't remove a key from a map while looping over it (line N); ...") only when the key is there;
  - `dup`: compact copy in the current arena, exact `cap = count`, `locks = 0`, `arena` = current arena.
- [ ] **Step 4: Run** `cargo test -p kestrel-runtime` and confirm it passes.

```rust
pub enum MapOp { Get, Has, Remove, Used, Live, Lock }
// ExprKind::Map(op, map, args): Get/Has/Remove take [key]; Live takes [index]; Used and Lock take none.
// Types: Get -> Optional(V); Has, Remove, Live -> Bool; Used, Lock -> I64.
ExprKind::MapNew
Stmt::MapSet(Place, Expr /*key*/, Expr /*value*/)
Stmt::MapUnlock(Place, Expr /*saved locks*/)
Proj::MapKey { at: Expr }
Proj::MapValue { at: Expr, checked: bool }
pub struct MapLayout { pub key_kind: i32, pub key_size: u32, pub val_off: u32, pub entry_size: u32, pub entry_align: u32 }
impl Module { pub fn map_layout(&self, key: ElemIdx, value: ElemIdx) -> MapLayout }
```
- Lowering:
  - a literal becomes `Seq([Let(t, MapNew), MapSet(t, k, v)...], Move(t))`;
  - `m.get(k, d)` becomes `Seq([Let(d', d), Let(o, Map(Get))], If(tag(o) != 0, payload(o), d'))`;
  - `m[k]` becomes `Map(Get)`, then `owned` (deep copy when `V` holds heap memory);
  - for-in follows the spec's sketch, with the unlock as a scope cleanup.

- [ ] **Step 3: Implement** `func/maps.rs`:
  - a key goes into a stack slot (scalar store, or `lower_into` for a string); the runtime gets the slot's address and the key kind from `map_layout`;
  - `MapNew` zeroes the header and stores `current_arena` at 56;
  - `Get` writes tag 0, or tag 1 plus a copy of the value from `entry + val_off`;
  - `MapSet` evaluates key, then value (into a temp if aggregate), then calls insert and stores the value;
  - `Used` loads @16; `Live` is `i < used && entry.live != 0`;
  - `Lock` loads @48, stores +1 and returns the old value; `MapUnlock` stores the saved value back;
  - projections: `entries + i * entry_size + 8` (key) or `+ val_off` (value); a checked value panics with "a map changed while looping over it (line N)" when `!Live`;
  - string `==`: both operands into slots, call `str_eq`, `Ne` flips.
