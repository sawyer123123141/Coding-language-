# Generics Implementation Plan: `struct Stack[T]`, `enum Result[T, E]`, `best[T](...)`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Build on `main`, with the ledger under `.superpowers/sdd/2026-10-24-generics/`.

**Goal:** User generics: placeholders on structs, enums and functions (`struct Stack[T]`, `enum Result[T, E]`, `pure best[T: Damageable + Named](...)`), the three built-in rules `equatable`, `ordered`, `key`, square-bracket type arguments in types and expressions, types worked out from values and the expected type, generic code checked once against its rules, and one compiled copy per generic and set of types in the whole program, which runs like the copy you would write by hand.

**Architecture:** The parser reads placeholder lists and parses "brackets after a name" both ways; a syntax pass (`settle.rs`, run at the end of `parse()` and `link()`) turns each into `Index`, `TypeCall` or the new `TypeApply`, so the checker never sees the undecided node. The checker gets `Ty::Param(ParamId)`, interned type lists, and generic types as **instances** (`Stack[int]` is a `StructId` of its own with its fields filled in, so every type question works unchanged); generic bodies are checked once with the strict answers for `T` (R4); calls work out their types (`generic/infer.rs`); after every body, the collection pass (`generic/copies.rs`) appends one `FnInfo` per copy and interns every type a copy's lowering reads, then the tables are frozen. KIR lowering reads every checker type and resolution through one substitution-aware accessor (`lower/subst.rs`) and lowers each copy from the generic's declaration; generic originals become trapping stubs. Range analysis, the inliner, contracts and codegen see ordinary functions.

**Tech Stack:** Rust, Cranelift 0.137. Tests are Rust unit tests plus `.kes` program, error and CLI tests.

**Spec:** `docs/superpowers/specs/2026-10-24-generics-design.md` (committed 236d238), from the approved proposal `docs/superpowers/plans/2026-10-24-generics-proposal.md`. Every message, rule and number comes from the spec, which wins any conflict, except where a **plan ruling** below (P1-P20) says the spec's text is wrong or silent; each ruling says why and what it costs if wrong. Rulings G1-G27 and R1-R8 are the spec's.

## Global Constraints

- **Soundness first.** Generic code is where a copy could become unsafe. Critical bugs, each a stop for review: any answer the checker gives for `T` (or a type containing it) that refuses less code than the R4 table (a `has_heap` of false lets a `string` copy outlive its arena; `is_aggregate` false breaks the exclusivity and changed-later rules); an instance whose owning-ness isn't its declaration's, including **an instance interned after `compute_owning` with no entry in `owning_structs`/`owning_enums`** (`is_owning` reads a missing entry as `false` today: a double free); a type allowed as `T` that R3/R7 refuses (owning, optional, function type, anything holding a function, a missing rule); inference letting the expected type change a placeholder the values decided, or widening a placeholder that must match exactly; lowering reading a checker type or resolution without the copy's substitution, or making a checker type (G13: lowering only looks types up and panics on a miss); a KIR type that names a placeholder layout (a non-concrete struct, enum or element); a copy reusing another copy's closure code, environment layout, list or sort helper, method table or `@prove` site; a recorded conversion or borrow dropped when its substituted source and target differ (G14 drops only equal ones); two different type lists interned as one, or one copy made twice; the driver letting a generic reach KIR before Task 6b; interning that loops on a declaration the expansion check refused. Where a rule is unclear, refuse the program.

## Plan rulings

Each is the plan's, with what it costs if wrong. The ones that correct the spec are flagged **(spec correction)**.

- **P1. The generic tables are one field, `Tables::generic: Generics`** (defined in `check/src/generic/mod.rs`), and `ListMethod` moves from `tables.rs` to `check/src/list_method.rs` (re-exported from `tables`), so `tables.rs` stays under 400 lines with the new `StructInfo`/`EnumInfo`/`FnInfo` fields. Cost: `t.generic.type_args` instead of the spec's `t.type_args`.
- **P2. Copy notes are `Module::copies: HashMap<FuncIdx, CopyNote>`,** not a `Func` field: `Func { ... }` is built in 32 places, and function indexes never change after lowering. Cost: none visible.
- **P3. `check_args`'s pre-checked mode lands in Task 4,** with inference, its only user. Task 3a gives `check_args` a signature to check against (`CallSig { fid, params, ret }`, the callee's own or substituted). Cost: none.
- **P4. Every per-copy cache in lowering is keyed by the active substitution, `Option<Subst>`, not `Option<FnId>`** **(spec correction)**. A closure in a generic struct's field default is lowered at a construction in plain code (no copy) under the instance's substitution: keyed by the function, `Box[int]` and `Box[string]` would share one closure code with `Box[int]`'s types. The key is `(ExprId, Option<Subst>)` for `Helpers::closures`, `env_copies`, `env_layouts`, and `(annotation, Option<Subst>)` for `Proves::loops`. Cost: none.
- **P5. `<` on strings lowers to `StrOp::Cmp(a, b)` compared with 1** **(spec correction)**: `Cmp` gives a `u8`, 0 before, 1 equal, 2 after (`kir/src/ops.rs`), not -1/0/1; `a < b` is `cmp < 1`, `<=` is `cmp <= 1`, `>` is `cmp > 1`, `>=` is `cmp >= 1`. Bools compare their `u8` values. Cost: none.
- **P6. A copy's contract error is today's sentence with the clause on the target** **(spec correction)**: "`Stack[string].put` (made by `Stack[string]` on line 12) can't be proven `no_alloc`: it allocates on line 5: ..." (Task 9's test). The spec says "today's wording plus the clause" and that `words::target` appends it, but its example sentence ("`@prove(no_alloc)` on ... doesn't hold") isn't today's wording. Cost: wording only.
- **P7. Messages the spec doesn't word** are the "(plan)" ones in Global Constraints, in today's style. Cost: wording only.
- **P8. A unit variant takes the expected type too** **(spec gap)**: `let m: Maybe[int] = Maybe.Nothing` is a `Field`, so `check_field` and the variant-value path take the expected type, not only `check_method_call`, `check_type_call` and `variant_construct`. Cost: none.
- **P9. Where the endless-copy errors go.** The static checks report once per cycle, at the first declaration of the cycle in source order, and every declaration in the cycle is marked `endless` (its instances keep `Error` fields, so nothing loops). When the static function check reports, the collection walk doesn't run. The cap reports at the declaration of the generic whose copy passed it, showing that generic's first two copies on the `made_by` chain. Cost: error positions only.
- **P10. One inference error per call:** the first conflict as it happens, or the first undecided placeholder in declaration order. Deferred arguments not yet checked are then skipped (no follow-on "give `x` a type"). Cost: a second mistake in the same call shows after the first is fixed.
- **P11. A collection literal decides a placeholder through its parameter** **(spec inconsistency)**. Step 1 checks an argument with no hint while its parameter's type is still open, and an unhinted `[1, 2]` is an *array* (`check_array_lit`), so `list[T]` would never meet it: `count([1, 2])` couldn't tell `T`, and the spec's own G7 example (`let s: Stack[float] = Stack(items: [1, 2])` failing because "`T` is `int` from the list") couldn't happen. Rule: a non-empty array literal given for an open `list[...]` (or `[...]`) parameter is checked without a hint; its items decide its element type, it meets the parameter as `list[X]`, and its recorded type becomes `list[X]` (as a hint would have made it). Empty `[]`, `none` and `{}` stay deferred (step 3). Cost: if wrong, those calls need written types.
- **P12. The temporary refusals and panics** in Global Constraints. Cost: none after Task 8.
- **P13. A placeholder can't take the own (unqualified) name of any struct, enum or interface in the program, or a built-in type name.** Cost: one check.
- **P14. R3 and R7 messages name the placeholder** (`can't be `A` yet` in `Pair[A, B]`), not always `T`. Cost: wording.
- **P15. `Proves::new` skips generic originals from Task 6b** (the spec has it in Task 9), so an annotated generic's trapping stub is never judged (`no_panic` would fail on it). Cost: none.
- **P16. Two guards behind G13.** `subst_known` panics on a miss; and `lower()` ends with a walk of the finished module that panics ("a generic type reached KIR unsubstituted; this is a compiler bug") when any local or expression type names a non-concrete struct, enum or element (`kty` of `list[T]` is a `KTy::List` of a placeholder element, not a `Ty::Param`, so `kty`'s own panic can't see it). Cost: one walk per compile (measure in Task 11; under 1% expected).
- **P17. `is_const_expr`: a `TypeCall` is constant only for the built-in names and generic struct constructions** **(spec gap)**: after settling, `best[int](xs)` is a `TypeCall` too, and today's `TypeCall => all(args)` arm would accept a function call in a constant. `TypeApply` is constant (G19); a `MethodCall` or `Field` on a `TypeApply` naming an enum is constant like `Enum.Variant`. ## Review Focus

1. **A permissive answer for `T`** (R4): `has_heap`, `is_aggregate`, `holds_uncomparable`, `zero_fill_breaks`, `coerces_to`, `map_ty`, sortability; an arena escape or changed-later check skipped in generic code that the same code written for `string` hits. (Tasks 2a, 3a.)
2. **Owning-ness and termination of instances**: an instance interned late without an owning entry; interning a refused (`endless`) declaration; self-containment through a generic missed, or reported on an instance. (Tasks 2a, 2b.)
3. **Inference**: the expected type overriding a decided placeholder; exactness through `var`, inside types and closure results; a widened placeholder whose earlier argument isn't converted; deferred order; R3/R7 on worked-out types. (Task 4.)
4. **Copies**: one per (generic, types); every type a copy's lowering reads interned; copies through rule calls, interface conversions of instances, field defaults and constants; the static checks and the cap. (Task 5.)
