**Plan 2 rulings made on the user's behalf** (what each costs if wrong):
- **A. Natives use Kestrel's own calling convention:** aggregates by pointer, a string is a pointer to its 16-byte header, an enum a pointer with the tag first, an aggregate result through a pointer passed first, `bool` and `u8` zero-extended. The first design said "pointer and length" and "enum as its tag". Cost: a native reads one more indirection.
- **B. `FnDecl.is_native: bool` with an empty body block,** instead of `Option<Block>`. Cost: a bodyless function looks like an empty one to code that forgets the flag (the inliner was fixed explicitly).
- **C. Constants** (changed in the final review): constants are checked in dependency order, a depth-first walk over the constants each one uses. So `let BG = draw.BLACK` works, a module's `pub let SKY = draw.BLUE` works whatever the `use` order, and a constant may use one declared below it. A loop (`let A = B`, `let B = A`) is an error that names it. Without a dependency, a module's constants still come before the entry file's. Cost: none known; the old "earlier constants" message now says "other constants".
- **D. Headless lines quote strings.** Cost: none (a test-only format).
- **E. Memory is measured with a runtime arena report** (`KESTREL_ARENA_REPORT=1`), not a process's working set. Cost: one more test-only environment variable.
- **F. All subagents on Sonnet** (the user is asked before Opus).
- **G. A native struct parameter may have `string` fields.** Cost: none; a one-line change in `check/src/natives.rs::param_ok`.
- **H. The `builtin_modules.kes` program test moved to Task 5,** because the JIT needs every native registered; a driver test with no-op natives covers Task 3. Cost: none.
- **I. Native parameters skip the linker's "already imported" name check,** so `draw.text(text: string, ...)` stays as written. Cost: none observable.
- **J. Struct constructions are allowed in constants only.** A field default may construct only `vec2` and `vec3`, and can't use a constant whose type holds a user struct; `default_allocates` is conservative. This closed a dangling default and a default cycle. Cost: `tint: Color = draw.WHITE` isn't available yet.
- **K. The memory test's control text is longer than `"n {n}"`,** because the brief's text grows only 655,360 bytes in 100,000 frames, under the control's 1 MiB bound. The real program still uses `"n {n}"`. Cost: none.
- **L. The checker treats a native call's arguments as a scoped region** when one is directly an interpolated string, like `arena { }`: "this memory is freed when the call to `draw.text` returns, but `x` lives longer". Cost: exotic code (a store inside such an argument's block) gets an error instead of compiling.
- **M. `window.frame()` flushes `print` output each frame** (Task 8). `print` is buffered until the program ends, so without this the demo's once-a-second lines would show only at exit. Cost: one flush per frame, which is a stdout lock when nothing was printed and a write when something was.
- **N. Heap constants are re-allocated at each use; documented, hoisting decided in the 3D spec** (final review). An array, list or map constant (or a struct holding one) is re-lowered at every use (`kir/src/lower/expr.rs`, `const_value`). Cost: in a frame loop a three-colour palette array grew the program arena by 4.78 MB over 100,000 frames. The window spec's frame-loop paragraph says to wrap the loop body in `arena { }` or copy the constant into a `let` before the loop; the follow-ups list the hoisting decision.

### The final review (fixed after plan 2)

The final whole-branch review found, and these commits fixed:
- **Constants were checked in load order**, so `palette.kes` with `pub let SKY = draw.BLUE` failed unless `use draw` came first (ruling C).
- **`struct Node { next: Node? }` crashed the compiler** (stack overflow in KIR layout). An optional holds its payload in place, so it is now a "contains itself" error (with a help line pointing at `list[Node]` and `[Node]`, which keep their items elsewhere), also for mutual cycles (`A { b: B? }`, `B { a: A? }`). KIR's `has_heap` also guards against a type it is already inside.
- **The harness wasn't hermetic.** Every CLI test now strips `KESTREL_*` from the child's environment (`cli/tests/common`), and a window program without `// env: KESTREL_HEADLESS=...` is a harness panic.
- **Test gaps:** codegen tests for `u8` and `bool` native arguments that a native reads as a full `u32` (they fail without the `.uext()`) and for a mixed-width struct passed to a native; the real-window smoke test draws every shape and text, and its visible-window retry happens only when the hidden run behaved.
- Small things: the spec's environment-variable lead-in, the GLFW wording, the scratch-arena measurement wording, the "rename the program" message, the field-default message, `pub pure native` in the native-table test, `program_bytes()` only when asked, a dead `by_name` insert, and raylib INFO lines in `png_pixel`.

**Plan 1 rulings made on the user's behalf:**
- **Strings are heap values now,** like arrays: copying one copies its bytes, and the escape check covers them.
  - Storing a non-literal string into a longer-lived place needs `in x.mem { }`, for example `self.name = n` through `var self`.
  - Cost if wrong: string-heavy code is clumsier; a friendlier rule would be a language change.
- **String-key maps are 35% slower** in `bench/maps`, because `let w = words[i]` now copies. Accepted for now; there's a follow-up to let read-only copies share bytes.
- **Map keys are copied when they add an entry,** decided in KIR with the same freshness rule `owned` uses for every copy. Cost if wrong: an extra key copy.
- **`block_value` hands back a `Move` of its spill:** when a block declares an owning local, its tail goes through `owned(..)` into a temp and the temp is moved out. Cost if wrong: a missed or doubled copy for some tail shape. One shape still dangles (see the follow-ups).
- **Math names are reserved** like `print`, with the existing message "`min` is a built-in name; pick another". The vector method names aren't reserved.
- **`randf` stays below 1 at `float`:** a demoted 1.0 becomes 0.99999994, so `int(randf() * n)` never indexes past the end. Godot's `randf` is inclusive. Cost if wrong: a one-in-33-million draw differs.
- **`operand` copies indexed vector places,** so the index is evaluated once (`vs[next()].length()`). It also fixed vector `+` and swizzles. Cost if wrong: an extra copy of an indexed vector per operation.
- **All subagents run on Sonnet,** the final review included.
- **Fixed in the final review:** a `T` used as a `T?` wasn't copied (`in h.mem { h.s = k }` with `s: string?` or `[int]?` dangled, as did `Player(name: n, nick: n)`). `owned` now copies the payload of a `Some`; `tests/programs/optional_copies.kes` covers it.

- **Open from `par for`:** SIMD, the other half of sub-project 3 in the syntax spec, isn't started.
- **Checks cost 2.4x on the 3D world**, because each overflow check is a branch that keeps work in the loop. Range analysis could drop many of them; the follow-ups list has the details.

## Known gaps

`docs/superpowers/plans/2026-10-09-core-2a-followups.md` lists them. The notable ones:
- A `pure` function can't call a helper that fills a `var` local.
- `let ... else` always moves or copies.
- Runtime errors don't name the file.
- The add-on is Windows-only, and so is the standalone window (the window must move to the main thread for macOS).
- Runtime errors from natives name the function, not the line.
- The Godot bridge costs a few ms per 32 calls (the hop to its worker thread).
